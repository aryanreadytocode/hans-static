## 🔹 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/hans-static.git
   cd hans-static
   ```
2. Install dependencies:

   ```bash
   npm install
   ```
3. Run locally:

   ```bash
   npm run dev
   ```
4. Open in browser:

   ```
   http://localhost:3000
   ```
